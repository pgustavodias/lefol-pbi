# 💻 Tutorial — Download e Instalação do Power BI Desktop

# 📊 Introdução

O **Power BI Desktop** é a principal ferramenta da Microsoft para criação de dashboards, análises interativas e projetos de Business Intelligence.

Neste tutorial, você aprenderá como:

✅ Fazer o download oficial do Power BI Desktop  
✅ Instalar corretamente no Windows  
✅ Realizar a primeira abertura da ferramenta  
✅ Validar se a instalação ocorreu com sucesso

---

# 🔽 1. Download do Power BI Desktop

## Acesse o site oficial da Microsoft

Clique no link abaixo:

🔗 https://www.microsoft.com/pt-br/download/details.aspx?id=58494

---

## Localize o botão de download

Na página oficial, clique na opção e, após extrair o arquivo, execute-o e siga o processo de instlação convencionarl para ambiente Windows.

---

# 🖥️ 2. Requisitos Mínimos

Antes da instalação, verifique se seu computador atende aos requisitos básicos.

## Recomendado

| Recurso | Recomendação |
|---|---|
| Sistema Operacional | Windows 10 ou superior |
| Memória RAM | 8 GB ou mais |
| Processador | 64 bits |
| Espaço em Disco | 2 GB livres |
| Internet | Necessária para download e publicação |

---

# ⚠️ Importante

Atualmente, o Power BI Desktop possui suporte oficial apenas para Windows.

Usuários Mac podem utilizar:

- Máquina virtual Windows
- Parallels Desktop
- Azure Virtual Desktop

---

# 📥 3. Instalando o Power BI Desktop

## Opção 1 — Microsoft Store (Recomendada)

Ao abrir a página da Microsoft Store:

1. Clique em **Instalar**
2. Aguarde o download
3. A instalação ocorrerá automaticamente

---

## Opção 2 — Instalador Manual (.exe)

Caso utilize o instalador manual:

1. Faça o download do arquivo `.exe`
2. Execute o instalador
3. Clique em:

- Avançar
- Aceitar termos
- Instalar

4. Aguarde a conclusão

---

# ✅ 4. Primeira Abertura

Após instalar:

1. Abra o **Power BI Desktop**
2. Aguarde carregamento inicial
3. Feche eventuais telas de introdução (opcional)

Na tela principal você verá:

- Página inicial
- Botão “Obter Dados”
- Área de relatórios
- Painéis laterais

# ❓ Problemas Comuns

## O Power BI não abre

Verifique:

- atualização do Windows;
- permissões do usuário;
- antivírus bloqueando instalação.

---

## Instalação muito lenta

Possíveis causas:

- conexão instável;
- pouco espaço em disco;
- memória insuficiente.

---

## Erro de arquitetura

Certifique-se de instalar a versão compatível com seu sistema operacional (64 bits).
