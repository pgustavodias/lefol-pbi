## 🚀 Sobre o Curso

Este repositório reúne os materiais utilizados no curso:

# **Power BI na Prática — Do Dado à Decisão**

O objetivo do treinamento é desenvolver uma visão profissional sobre análise de dados, Business Intelligence e construção de dashboards estratégicos utilizando o Microsoft Power BI.

Mais do que aprender gráficos e fórmulas, o foco do curso está em:

- transformar dados em informação;
- gerar inteligência para tomada de decisão;
- construir dashboards profissionais;
- compreender conceitos essenciais de BI e modelagem;
- desenvolver pensamento analítico orientado a resultados.

---

# 🎯 Objetivos do Curso

Ao final do treinamento, espera-se que o aluno seja capaz de:

✅ Importar e transformar dados no Power BI  
✅ Aplicar técnicas de ETL utilizando Power Query  
✅ Construir modelos relacionais adequados  
✅ Criar medidas e indicadores utilizando DAX  
✅ Desenvolver dashboards interativos e executivos  
✅ Aplicar boas práticas de design e storytelling com dados  
✅ Criar análises voltadas ao contexto corporativo
